# 🏗️ 系统架构设计

## 系统概览

YOLOv8篮球训练辅助系统采用前后端分离的架构设计，结合深度学习模型提供实时的篮球训练分析服务。

## 模块设计

### 1. 前端模块 (Frontend)

#### 1.1 用户认证模块
- **功能**: 用户注册、登录、登出
- **技术**: HTML5 Forms, JavaScript Fetch API
- **特点**: 
  - 表单验证
  - Session管理
  - 友好的错误提示

#### 1.2 实时检测模块
- **功能**: 摄像头视频流实时处理
- **技术**: WebRTC, Canvas API
- **流程**:
  1. 获取摄像头权限
  2. 捕获视频帧
  3. 发送到后端处理
  4. 显示处理结果
  5. 实时反馈建议

#### 1.3 视频分析模块
- **功能**: 上传视频文件进行批量分析
- **技术**: File API, FormData
- **流程**:
  1. 选择视频文件
  2. 上传到服务器
  3. 后端处理分析
  4. 显示分析报告
  5. 数据可视化

#### 1.4 历史记录模块
- **功能**: 查看训练历史和统计
- **技术**: RESTful API, Dynamic DOM
- **特点**:
  - 卡片式展示
  - 得分可视化
  - 点击查看详情

### 3. AI模型模块 (Models)

#### 3.1 篮球检测器 (BasketballDetector)
```python
BasketballDetector
├── 模型: YOLOv8n
├── 检测类别: 
│   ├── Person (人)
│   └── Sports Ball (篮球)
│
├── 主要方法:
│   ├── detect()                        # 通用检测
│   ├── detect_basketball_and_players() # 专项检测
│   └── draw_detections()               # 结果可视化
│
└── 配置参数:
    ├── conf_threshold: 0.25
    ├── iou_threshold: 0.45
    └── device: cpu/cuda
```

#### 3.2 姿态估计器 (PoseEstimator)
```python
PoseEstimator
├── 模型: YOLOv8n-pose
├── 关键点: 17个COCO关键点
│   ├── 头部: nose, eyes, ears
│   ├── 上身: shoulders, elbows, wrists
│   ├── 下身: hips, knees, ankles
│
├── 主要方法:
│   ├── estimate()            # 姿态估计
│   ├── get_keypoint()        # 获取关键点
│   ├── calculate_angle()     # 计算角度
│   ├── draw_pose()           # 绘制姿态
│   └── get_body_height()     # 计算身高
│
└── 骨架连接: 19对连接线
```

#### 3.3 投篮分析器 (ShotAnalyzer)
```python
ShotAnalyzer
├── 依赖: PoseEstimator
│
├── 分析维度:
│   ├── 肘部角度 (60-110°最佳)
│   ├── 出手高度 (相对身高1.3倍以上)
│   ├── 身体对齐 (肩膀水平度)
│   └── 投篮手识别 (左/右)
│
├── 主要方法:
│   ├── analyze_shooting_form()  # 分析投篮姿势
│   ├── is_shooting_moment()     # 判断投篮时机
│   └── generate_report()        # 生成报告
│
└── 评分系统:
    ├── 满分: 100分
    ├── 三个维度各33.3分
    └── 实时反馈建议
```

#### 3.4 篮筐检测器 (HoopDetector)
```python
HoopDetector
├── 检测方法:
│   ├── 颜色检测 (HSV空间)
│   │   ├── 橙色范围: [5, 100, 100] - [25, 255, 255]
│   │   └── 红色范围: [0-10, 160-180]
│   │
│   └── 轮廓检测
│       ├── 边缘检测 (Canny)
│       ├── 轮廓提取
│       └── 椭圆拟合
│
├── 主要方法:
│   ├── detect()              # 检测篮筐
│   ├── draw_detections()     # 绘制结果
│   └── get_closest_hoop()    # 获取最近篮筐
│
└── 特点:
    ├── 无需训练
    ├── 实时性高
    └── 鲁棒性好
```

## 数据流

### 实时检测流程
```
用户 → 开启摄像头 → 捕获帧 → Base64编码 → 
发送到后端 → 解码 → 检测处理 → 分析 → 
绘制结果 → 编码 → 返回前端 → 显示
```

### 视频分析流程
```
用户 → 选择视频 → 上传 → 保存到服务器 → 
创建训练记录 → 逐帧处理 → 检测分析 → 
保存结果 → 生成报告 → 更新记录 → 
返回结果 → 展示
```

## 技术选型理由

### 1. Python + Flask
- 快速开发
- 生态丰富
- AI库支持好

### 2. YOLOv8
- 最新SOTA模型
- 速度快精度高
- 易于使用

### 3. SQLite
- 轻量级
- 零配置
- 单机足够

### 4. 原生JavaScript
- 无需打包
- 加载快
- 易于调试
