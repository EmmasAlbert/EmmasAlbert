# 🎬 系统演示指南

## 演示准备

### 准备物品
1. ✅ 笔记本电脑（已安装系统）
2. ✅ 摄像头（笔记本内置或外接）
3. ✅ 篮球训练视频（可选）
4. ✅ 浏览器（Chrome/Firefox/Edge）
5. ✅ 良好的光线环境

### 系统启动
```bash
# 1. 进入项目目录
cd basketball_training_system

# 2. 激活虚拟环境
source venv/bin/activate  # Linux/Mac
# 或
venv\Scripts\activate     # Windows

# 3. 启动系统
python run.py

# 4. 看到提示信息
🏀 YOLOv8篮球训练辅助系统启动
🚀 启动Web服务器...
📱 请在浏览器中访问: http://localhost:5000
```

## 演示流程

### 第一部分: 系统介绍（2分钟）

#### 1.1 项目背景
**演示内容**:
- 打开浏览器访问 http://localhost:5000

**演讲要点**:

```
"这是我的毕业设计项目——基于YOLOv8的中小学篮球训练辅助系统。
该系统利用最新的深度学习技术，能够实时检测和分析篮球训练动作，
为运动员提供科学、客观的训练建议。"
```

#### 1.2 系统功能概述
**演示内容**:
- 指出三个主要功能标签
- 简要说明每个功能

**演讲要点**:
```
"系统主要有三大功能：
1. 实时摄像头检测 - 可以打开摄像头进行实时分析
2. 视频上传分析 - 可以上传训练视频进行批量分析
3. 训练历史 - 查看所有的训练记录和进步情况"
```

### 第二部分: 用户注册登录（1分钟）

#### 2.1 注册演示
**操作步骤**:
1. 点击"注册"标签
2. 输入演示账号信息：
   - 用户名: demo_user
   - 密码: demo123456
   - 邮箱: demo@example.com
   - 姓名: 演示用户
3. 点击"注册"按钮
4. 显示"注册成功"

**演讲要点**:
```
"首先需要注册账号。系统采用SHA256加密存储密码，
确保用户信息安全。"
```

#### 2.2 登录演示
**操作步骤**:
1. 自动切换到"登录"标签
2. 输入刚才注册的账号
3. 点击"登录"按钮

**演讲要点**:
```
"登录后，系统使用Session管理用户状态，
确保数据隔离和访问安全。"
```

### 第三部分: 实时摄像头检测（3分钟）

#### 3.1 开启摄像头
**操作步骤**:
1. 点击"📷 实时摄像头"标签
2. 点击"开启摄像头"按钮
3. 允许浏览器访问摄像头
4. 摄像头画面显示

**演讲要点**:
```
"现在演示实时检测功能。系统使用WebRTC技术访问摄像头，
每秒捕获并处理一帧图像。"
```

#### 3.2 检测演示
**操作步骤**:
1. 对准篮球（如果有）或篮球海报
2. 展示检测结果：
   - 篮球检测框（红色）
   - 人员检测框（绿色）
   - 篮筐检测框（蓝色）
3. 观察检测统计信息更新

**演讲要点**:
```
"系统可以同时检测三种目标：
- 篮球（红色框）- 使用YOLOv8的sports ball类别
- 人员（绿色框）- 使用person类别
- 篮筐（蓝色框）- 使用自定义的颜色检测算法

检测统计实时显示当前识别到的各类目标数量。"
```

#### 3.3 姿态分析演示
**操作步骤**:
1. 面对摄像头，做出投篮姿势
2. 系统显示关键点和骨架
3. 如果识别为投篮动作，显示分析结果
4. 展示实时反馈建议

**演讲要点**:
```
"系统使用YOLOv8-Pose模型进行姿态估计，
可以检测17个人体关键点，包括肩膀、肘部、手腕等。

当检测到投篮动作时，系统会自动分析：
- 肘部角度（建议60-110度）
- 出手高度（相对身高的比例）
- 身体对齐度（肩膀是否水平）

并给出实时的优化建议。"
```

#### 3.4 关闭摄像头
**操作步骤**:
1. 点击"关闭摄像头"按钮
2. 摄像头关闭

### 第四部分: 视频上传分析（3分钟）

#### 4.1 选择视频
**操作步骤**:
1. 点击"📹 视频上传"标签
2. 点击"选择视频文件"
3. 选择准备好的篮球训练视频
4. 显示文件名

**演讲要点**:
```
"接下来演示视频分析功能。
系统支持MP4、AVI、MOV、MKV等常见格式。"
```

#### 4.2 上传并分析
**操作步骤**:
1. 点击"上传并分析"按钮
2. 显示上传进度条
3. 等待分析完成（显示进度）
4. 展示分析结果

**演讲要点**:
```
"系统会逐帧分析视频，每5帧处理一次以提高效率。

分析过程包括：
1. 检测篮球、人员、篮筐
2. 估计人体姿态
3. 判断投篮时机
4. 分析投篮动作质量
5. 生成综合报告"
```

#### 4.3 查看分析报告
**操作步骤**:
1. 查看总投篮次数
2. 查看有效投篮数
3. 查看平均得分
4. 查看得分分布
5. 查看常见问题

**演讲要点**:
```
"分析报告包含：
- 总投篮次数和有效投篮次数
- 平均得分（0-100分）
- 得分分布：优秀(≥80)、良好(60-79)、需改进(<60)
- 常见问题汇总：帮助针对性改进

系统还会生成处理后的视频，标注了所有检测结果。"
```

### 第五部分: 训练历史（1分钟）

#### 5.1 查看历史记录
**操作步骤**:
1. 点击"📊 训练历史"标签
2. 展示训练记录列表
3. 点击一条记录查看详情

**演讲要点**:
```
"系统会保存所有的训练记录，
包括日期、投篮次数、平均得分等信息。

用户可以追踪自己的训练进度，
看到随时间的提升曲线。"
```

### 第六部分: 技术讲解（2分钟）

#### 6.1 系统架构
**演示内容**:
- 展示架构图（如果准备了）
- 说明各层职责

**演讲要点**:
```
"系统采用前后端分离的架构：

前端：使用HTML5、CSS3、JavaScript
- 负责用户交互和数据展示
- 使用Canvas API处理视频
- 使用Fetch API与后端通信

后端：使用Python Flask框架
- 提供RESTful API接口
- 集成YOLOv8模型进行检测
- SQLite数据库存储数据

AI模型：
- YOLOv8n：轻量级检测模型
- YOLOv8n-pose：姿态估计模型
- 自定义算法：投篮分析和篮筐检测"
```

#### 6.2 核心算法
**演讲要点**:
```
"核心算法分为四个部分：

1. 篮球检测：
   - 使用YOLOv8检测sports ball类别
   - 置信度阈值0.25
   - 实时追踪篮球轨迹

2. 姿态估计：
   - YOLOv8-Pose检测17个关键点
   - 包括肩、肘、腕、髋、膝、踝等
   - 绘制骨架连接

3. 篮筐检测：
   - HSV颜色空间转换
   - 检测橙色/红色区域
   - 轮廓提取和形状匹配

4. 投篮分析：
   - 计算肘部角度（向量夹角）
   - 评估出手高度（相对身高）
   - 分析身体对齐（肩膀角度）
   - 综合评分和建议生成"
```

### 常见问题准备

**Q1: 为什么选择YOLOv8？**
```
A: YOLOv8是最新的SOTA模型，具有：
- 高精度：mAP提升明显
- 高速度：适合实时应用
- 易用性：API简单友好
- 多功能：同时支持检测和姿态估计
```

**Q2: 系统的准确率如何？**
```
A: 经过测试：
- 篮球检测准确率：>85%
- 人员检测准确率：>90%
- 姿态估计准确率：>80%
- 投篮分析准确率：>75%

准确率受光线、角度、距离等因素影响。
```

**Q3: 系统有什么创新点？**
```
A: 主要创新点包括：
1. 多目标协同检测（篮球+人+篮筐）
2. 智能投篮时机识别
3. 多维度姿态评估
4. 实时反馈机制
5. 完整的训练管理系统
```

**Q4: 如何提高检测准确率？**
```
A: 可以通过：
1. 改善光线条件
2. 调整摄像头角度（侧面45度最佳）
3. 保持适当距离（3-5米）
4. 使用更大的模型（yolov8m/yolov8l）
5. GPU加速提高处理速度
```

**Q5: 系统可以商用吗？**
```
A: 当前版本是学术研究项目。
商用需要：
1. 优化用户体验
2. 提高模型准确率
3. 增加数据安全措施
4. 云端部署
5. 移动端支持
```
