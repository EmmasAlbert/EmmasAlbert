# 🎯 答辩速查卡 - 针对中小学生的适配性

## 核心问题：系统如何针对中小学生？

### 30秒标准回答 ⭐⭐⭐

```
"系统针对中小学生的适配体现在三个核心方面：

1️⃣ 评估标准适配
   - 使用相对值（相对身高）而非绝对值
   - 三档分龄：小学(50-120°)、初中(55-115°)、高中(60-110°)
   - 小学生标准更宽松，符合身体发育特点

2️⃣ 界面友好性
   - 简单直观的操作流程
   - 表情符号和颜色反馈（✓绿色 ✗红色）
   - 通俗易懂的语言，避免专业术语

3️⃣ 反馈针对性
   - 小学生：鼓励为主 "太棒了！🎉"
   - 初中生：指导为主 "优秀！继续保持"
   - 高中生：精准分析 "已达到较高水平"

系统架构灵活，支持教练在config.yaml中自定义各年龄段标准。"
```

## 技术细节备用 🔧

### 代码实现证明

**数据库字段**（database.py）：
```python
age INTEGER,              -- 年龄
student_level TEXT,       -- 学段：primary/junior/senior
school_name TEXT,         -- 学校名称
```

**自动适配逻辑**（shot_analyzer.py）：
```python
def _get_adapted_thresholds(self):
    # 根据年龄自动选择标准
    if age <= 12:
        return primary_thresholds
    elif age <= 15:
        return junior_thresholds
    else:
        return senior_thresholds
```

**反馈风格调整**（shot_analyzer.py）：
```python
if feedback_style == "鼓励为主":
    return "太棒了！🎉 你做得非常好！"
elif feedback_style == "指导为主":
    return "优秀！投篮动作规范。"
```
