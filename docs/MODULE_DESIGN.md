# 功能模块详细设计文档

## 模块优先级说明
- ⭐⭐⭐ 高优先级（核心功能，必须实现）
- ⭐⭐ 中优先级（重要功能）
- ⭐ 低优先级（增强功能）

---

## 1. 用户管理模块

### 1.1 用户注册登录 ⭐⭐⭐

**功能描述**:
- 支持手机号/邮箱注册
- 密码强度验证
- 验证码验证
- 忘记密码功能
- 第三方登录（微信、QQ）

**API接口**:
```
POST /api/auth/register - 用户注册
POST /api/auth/login - 用户登录
POST /api/auth/logout - 用户登出
POST /api/auth/reset-password - 重置密码
POST /api/auth/send-verification-code - 发送验证码
```

**数据库表**: users

### 1.2 用户信息管理 ⭐⭐⭐

**功能描述**:
- 个人资料编辑
- 头像上传
- 身体数据管理（身高、体重、臂展、手掌大小）
- 运动数据（运动年限、位置偏好）

**API接口**:
```
GET /api/users/profile - 获取个人信息
PUT /api/users/profile - 更新个人信息
POST /api/users/avatar - 上传头像
GET /api/users/{user_id} - 获取用户信息
```

**数据库表**: users, user_profiles

### 1.3 角色权限管理 ⭐⭐⭐

**功能描述**:
- 角色：学生、教练、管理员
- 权限控制：数据访问、功能使用
- 角色切换（教练可以是学生）

**API接口**:
```
GET /api/roles - 获取角色列表
POST /api/users/{user_id}/roles - 分配角色
GET /api/permissions - 获取权限列表
```

**数据库表**: roles, permissions, user_roles

### 1.4 班级/小组管理 ⭐⭐

**功能描述**:
- 教练创建班级
- 生成班级邀请码
- 学生加入班级
- 班级成员管理
- 班级统计数据

**API接口**:
```
POST /api/classes - 创建班级
GET /api/classes - 获取班级列表
POST /api/classes/{class_id}/join - 加入班级
GET /api/classes/{class_id}/members - 获取班级成员
DELETE /api/classes/{class_id}/members/{user_id} - 移除成员
```

**数据库表**: classes, class_members

## 2. 训练管理模块

### 2.1 实时训练模式 ⭐⭐⭐

**功能描述**:
- 摄像头实时采集
- WebSocket实时通信
- 实时AI分析反馈
- 投篮计数
- 命中率显示

**技术实现**:
- WebRTC视频采集
- Socket.IO推送
- YOLOv8实时检测
- 低延迟优化（<500ms）

**API接口**:
```
WebSocket /ws/training/realtime - 实时训练连接
POST /api/training/start-realtime - 开始实时训练
POST /api/training/end-realtime - 结束实时训练
```

### 2.2 视频上传分析 ⭐⭐⭐

**功能描述**:
- 支持MP4/AVI/MOV格式
- 分片上传大文件
- 异步分析处理
- 进度通知
- 分析结果查看

**API接口**:
```
POST /api/training/upload - 上传视频
GET /api/training/videos/{video_id} - 获取视频信息
GET /api/training/videos/{video_id}/analysis - 获取分析结果
DELETE /api/training/videos/{video_id} - 删除视频
```

**数据库表**: training_videos, video_analysis

### 2.3 训练计划制定 ⭐⭐

**功能描述**:
- 教练为学生制定计划
- 训练目标设定
- 训练内容安排
- 训练频率设置
- 计划模板

**API接口**:
```
POST /api/training/plans - 创建训练计划
GET /api/training/plans - 获取训练计划列表
PUT /api/training/plans/{plan_id} - 更新训练计划
DELETE /api/training/plans/{plan_id} - 删除训练计划
```

**数据库表**: training_plans, plan_items

### 2.4 训练记录管理 ⭐⭐⭐

**功能描述**:
- 训练历史查询
- 按时间筛选
- 按类型筛选
- 详细数据查看
- 导出记录

**API接口**:
```
GET /api/training/records - 获取训练记录
GET /api/training/records/{record_id} - 获取记录详情
POST /api/training/records - 创建训练记录
DELETE /api/training/records/{record_id} - 删除记录
```

**数据库表**: training_records

## 3. AI分析模块

### 3.1 投篮检测 ⭐⭐⭐

**功能描述**:
- 篮球检测与追踪
- 篮筐位置识别
- 投篮动作识别
- 命中判断
- 出手点分析

**技术实现**:
- YOLOv8目标检测
- DeepSort追踪算法
- 关键帧提取
- 几何计算

**返回数据**:
```json
{
  "shot_detected": true,
  "ball_trajectory": [[x1,y1], [x2,y2], ...],
  "hoop_position": [x, y],
  "shot_result": "made/missed",
  "release_point": [x, y],
  "release_angle": 45.5,
  "ball_speed": 8.5
}
```

### 3.2 姿态分析 ⭐⭐⭐

**功能描述**:
- 17个关键点检测
- 关节角度计算
- 投篮姿态评分
- 姿态问题识别
- 改进建议

**技术实现**:
- MediaPipe Pose
- 角度计算算法
- 姿态评分模型
- 标准姿态对比

**关键点**:
- 肩膀、肘部、手腕
- 髋部、膝盖、脚踝
- 头部、脊柱

**返回数据**:
```json
{
  "keypoints": [...],
  "angles": {
    "elbow": 90.5,
    "knee": 135.2,
    "release_angle": 45.0
  },
  "pose_score": 85,
  "issues": ["手肘角度偏小", "膝盖未充分弯曲"],
  "suggestions": ["加大手肘弯曲", "降低重心"]
}
```

### 3.3 动作对比 ⭐⭐

**功能描述**:
- 与标准动作对比
- 与NBA球星动作对比
- 相似度评分
- 差异可视化
- 学习建议

**技术实现**:
- DTW（动态时间规整）
- 姿态序列对比
- 特征相似度计算

### 3.4 轨迹分析 ⭐⭐

**功能描述**:
- 篮球飞行轨迹
- 弧线高度分析
- 入框角度分析
- 最佳轨迹推荐
- 3D轨迹可视化

**技术实现**:
- 抛物线拟合
- 3D重建
- 物理模型
