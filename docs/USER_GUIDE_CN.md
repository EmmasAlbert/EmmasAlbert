## 🎯 系统简介

### 这是什么系统？

这是一个基于人工智能的篮球训练辅助平台，专为中小学生设计。系统利用YOLOv8深度学习模型和MediaPipe姿态估计技术，提供：

- 🎥 **视频分析**：自动分析投篮动作，给出改进建议
- 📊 **数据统计**：跟踪训练进度，可视化展示数据
- 🎓 **在线学习**：提供分级课程和教学视频
- 🏆 **激励系统**：通过成就和排行榜激励训练
- 👥 **社交互动**：师生互动、分享训练成果

### 系统特点

✅ **智能分析**：AI自动识别篮球、球筐、人体姿态  
✅ **实时反馈**：训练时即时获得动作评估  
✅ **个性化**：根据个人数据生成定制化训练建议  
✅ **简单易用**：友好的用户界面，3步即可开始使用  
✅ **全平台支持**：支持网页、移动端访问

## 🚀 快速开始

### 方式一：使用Docker（最简单，推荐）

#### 前置要求
- Docker 20.10+
- Docker Compose 2.0+

#### 3步启动

```bash
# 步骤1: 克隆代码
git clone https://github.com/EmmasAlbert/EmmasAlbert.git
cd EmmasAlbert

# 步骤2: 启动所有服务
docker-compose up -d

# 步骤3: 访问系统
# 打开浏览器访问 http://localhost:3000
```

✅ **就这么简单！系统已经运行了**

#### 服务地址

| 服务 | 地址 | 说明 |
|------|------|------|
| 前端界面 | http://localhost:3000 | 主要使用界面 |
| API文档 | http://localhost:8000/api/docs | 开发者API文档 |
| MinIO控制台 | http://localhost:9001 | 文件存储管理（账号: minioadmin/minioadmin） |

#### 停止服务

```bash
# 停止但保留数据
docker-compose down

# 停止并清除所有数据（慎用）
docker-compose down -v
```

## 👥 按角色使用

### 👨‍🎓 学生用户

作为学生，你可以：
- 上传训练视频，获取AI分析
- 进行实时训练，获得即时反馈
- 查看个人统计数据和进步曲线
- 学习在线课程
- 完成教练布置的训练任务
- 查看排行榜，与同学比较

#### 学生使用流程

##### 1. 注册账号

访问 http://localhost:3000

1. 点击「注册」按钮
2. 填写注册信息：
   - 用户名（字母+数字，4-20位）
   - 邮箱
   - 密码（至少8位）
   - 选择角色：**学生**
3. 填写个人信息：
   - 姓名
   - 年龄
   - 身高、体重（可选）
4. 点击「提交」完成注册

##### 2. 登录系统

1. 输入用户名和密码
2. 点击「登录」
3. 首次登录会进入新手引导

##### 3. 上传训练视频

**场景**：你有一段投篮训练的视频，想让AI分析你的动作

**步骤**：
1. 进入「训练管理」→「视频分析」
2. 点击「上传视频」
3. 选择视频文件（支持MP4/AVI/MOV格式，建议<500MB）
4. 填写训练信息：
   - 训练日期
   - 训练类型（投篮/运球/传球等）
   - 备注（可选）
5. 点击「开始上传」
6. 等待上传完成（会显示进度条）
7. 系统自动开始AI分析（需要几分钟）

**分析完成后可以查看**：
- 📊 投篮命中率
- 🎯 投篮次数统计
- 🤸 姿态分析得分
- 📈 动作关键点分析
- 💡 AI改进建议

##### 4. 实时训练模式

**场景**：想要边训练边获得实时反馈

**步骤**：
1. 进入「训练管理」→「实时训练」
2. 点击「开始训练」
3. 允许摄像头权限
4. 调整摄像头角度：
   - 确保能完整拍到投篮动作
   - 光线充足
   - 背景简单
5. 点击「开始分析」
6. 开始训练，系统会：
   - 实时检测篮球和球筐
   - 分析投篮姿态
   - 显示命中/未命中
   - 给出即时评分
7. 结束时点击「停止训练」
8. 查看本次训练报告

##### 5. 查看个人数据

进入「数据分析」查看：

- **训练记录**：历史所有训练记录
- **统计图表**：
  - 命中率趋势图
  - 训练频率日历
  - 姿态得分变化
- **对比分析**：
  - 与同班同学对比
  - 与上周/上月对比
- **AI建议**：个性化改进建议

##### 6. 学习课程

1. 进入「课程学习」
2. 选择适合自己水平的课程：
   - 🟢 初级：基础动作和规则
   - 🟡 中级：技术提升
   - 🔴 高级：战术和策略
3. 观看教学视频
4. 完成课程作业
5. 查看学习进度

##### 7. 查看成就和排行榜

**成就系统**：
- 进入「我的成就」
- 查看已获得和未获得的徽章
- 完成任务解锁新徽章

**排行榜**：
- 班级排行榜：与同班同学比较
- 全站排行榜：与所有用户比较
- 排名依据：训练次数、命中率、姿态得分等

##### 8. 加入班级

1. 进入「班级管理」
2. 选择「加入班级」
3. 输入班级邀请码（由教练提供）
4. 点击「加入」

### 👨‍🏫 教练用户

作为教练，你可以：
- 创建和管理班级
- 查看学生训练数据

- 布置训练任务

#### 教练使用流程

##### 1. 注册教练账号

注册时选择角色为「教练」，需要提供：
- 教练资质证明（可选）
- 执教经验
- 专长领域

##### 2. 创建班级

1. 进入「班级管理」
2. 点击「创建班级」
3. 填写班级信息：
   - 班级名称（如"初级篮球班A"）
   - 年级/年龄段
   - 最大人数（建议20-30人）
   - 班级简介
4. 点击「创建」
5. 系统生成班级邀请码，分享给学生

##### 3. 管理学生

**查看学生列表**：
- 进入班级，查看所有成员
- 可以看到每个学生的：
  - 基本信息
  - 训练频率
  - 最近表现
  - 进步情况

**移除学生**（如需要）：
- 选择学生 → 点击「移除」

##### 4. 制定训练计划

**为单个学生制定**：
1. 进入「训练管理」→「训练计划」
2. 点击「新建计划」
3. 选择学生
4. 填写计划内容：
   - 计划名称（如"投篮精准度提升计划"）
   - 训练周期（如2周）
   - 每日训练内容：
     - 训练项目（投篮/运球/体能等）
     - 训练量（次数/时间）
     - 重点改进（根据学生数据）
   - 目标设定（如命中率提升10%）
5. 点击「保存并发送」

**为班级制定**：
- 选择「批量制定」
- 可以为全班设置相同计划
- 或按能力分组设置不同计划

##### 5. 布置作业

1. 进入「课程管理」→「作业」
2. 点击「布置作业」
3. 填写作业内容：
   - 作业名称
   - 截止日期
   - 作业要求（如"完成50次投篮练习并上传视频"）
   - 评分标准
4. 选择发布对象（全班/指定学生）
5. 点击「发布」

##### 6. 查看和点评学生表现

**查看训练视频**：
1. 进入「学生管理」
2. 选择学生
3. 查看其上传的视频
4. 观看AI分析结果

**添加点评**：
1. 在视频下方点击「添加点评」
2. 写下你的评价和建议：
   - 做得好的地方（表扬）
   - 需要改进的地方（具体指出）
   - 下一步建议（可操作的建议）
3. 可以标记视频中的具体时间点
4. 点击「发送」

学生会收到通知并查看你的点评。

##### 7. 数据分析和报告

**班级整体数据**：
- 进入「数据分析」→「班级统计」
- 可以看到：
  - 班级平均命中率
  - 训练活跃度
  - 进步最快的学生
  - 需要关注的学生

**生成报告**：
1. 选择时间段（周/月/学期）
2. 点击「生成报告」
3. 系统自动生成包含：
   - 班级整体表现
   - 个人进步排名
   - 数据可视化图表
   - AI分析和建议
4. 可以导出为PDF分享给学生和家长

##### 8. 发布课程

1. 进入「课程管理」→「我的课程」
2. 点击「创建课程」
3. 填写课程信息：
   - 课程标题
   - 难度级别（初级/中级/高级）
   - 课程简介
4. 上传教学视频
5. 添加课程内容：
   - 知识点讲解
   - 示范动作
   - 训练要点
6. 设置课程目标和练习
7. 点击「发布」

## 🔧 核心功能详解

### 1. 视频上传和分析

#### 支持的视频格式
- MP4（推荐）
- AVI
- MOV
- 文件大小：建议 < 500MB
- 分辨率：建议 >= 720p
- 帧率：建议 >= 30fps

#### 视频拍摄建议

**摄像机位置**：
- 距离：3-5米
- 高度：与篮筐同高或稍低
- 角度：侧面45度角最佳

**环境要求**：
- 光线充足（避免逆光）
- 背景简单（避免人群）
- 完整拍到投篮动作（从准备到结束）

#### AI分析内容

系统会自动分析：

1. **球员检测**
   - 识别球员位置
   - 追踪球员移动

2. **篮球检测**
   - 识别篮球位置
   - 追踪篮球轨迹
   - 计算投篮弧度

3. **篮筐检测**
   - 定位篮筐位置
   - 判断投篮是否命中

4. **姿态分析**
   - 33个身体关键点检测
   - 分析投篮姿势：
     - 持球姿势
     - 起跳高度
     - 手臂角度
     - 手腕动作
     - 身体平衡
   - 与标准动作对比
   - 生成姿态评分（0-100分）

5. **统计数据**
   - 总投篮次数
   - 命中次数
   - 命中率
   - 平均出手速度
   - 最佳投篮位置

#### 查看分析结果

分析完成后（通常需要5-10分钟），你会收到通知。进入「训练记录」可以看到：

- **视频回放**：可以在视频上看到AI标注
- **数据报告**：详细的统计数据和图表
- **改进建议**：AI生成的个性化建议
- **对比分析**：与历史数据对比

### 2. 实时训练模式

#### 使用场景
- 日常训练时想获得即时反馈
- 教练指导时需要实时数据
- 想要记录训练过程

#### 技术要求
- 摄像头：建议1080p
- 网络：稳定的网络连接
- 浏览器：Chrome/Edge（推荐）

#### 使用步骤

1. **准备阶段**
   - 打开实时训练页面
   - 允许摄像头权限
   - 调整摄像头角度和位置
   - 确保画面中能看到篮筐

2. **校准阶段**
   - 系统会让你投1-2球进行校准
   - 确认篮筐位置
   - 调整检测灵敏度

3. **训练阶段**
   - 点击「开始训练」
   - 进行正常投篮练习
   - 系统实时显示：
     - 是否命中（✓ 或 ✗）
     - 姿态评分
     - 投篮轨迹
     - 累计统计
   
4. **结束阶段**
   - 点击「结束训练」
   - 查看本次训练总结
   - 可以选择保存视频

#### 实时反馈

在训练过程中，你会看到：
- 🟢 绿色：姿态标准，继续保持
- 🟡 黄色：姿态一般，注意调整
- 🔴 红色：姿态不佳，需要改进

系统还会语音提示（可关闭）：
- "很好，保持这个姿势"
- "手肘再高一点"
- "注意身体平衡"

### 5. 成就和排行榜

#### 成就系统

**成就类别**：

📊 **训练成就**
- 首次训练
- 连续训练7天/30天/100天
- 累计训练100/500/1000次
- 训练时长100/500/1000小时

🎯 **技术成就**
- 命中率达到50%/70%/90%
- 姿态得分达到80/90/95分
- 完成1000/5000/10000次投篮

🎓 **学习成就**
- 完成第一个课程
- 完成10/50/100个课程
- 学习时长100/500/1000小时

🏆 **竞技成就**
- 班级排名前10/前3/第1
- 周冠军/月冠军/年冠军
- 挑战赛获胜

#### 排行榜

**班级排行榜**：
- 只显示同班同学
- 按总积分排序
- 每周更新

**全站排行榜**：
- 显示所有用户
- 可以按不同指标排序：
  - 总积分
  - 命中率
  - 训练次数
  - 姿态得分

**积分规则**：
- 完成一次训练：+10分
- 命中一次：+1分
- 姿态评分>=90：+5分
- 完成一个课程：+50分
- 获得成就：+100分
- 连续训练：每天+5分额外奖励

## ❓ 常见问题

### 使用问题

#### Q1: 系统支持哪些设备？

**A**: 系统支持：
- 💻 电脑（Windows/Mac/Linux）
- 📱 手机和平板（iOS/Android）
- 推荐使用Chrome或Edge浏览器

#### Q2: 视频上传失败怎么办？

**A**: 请检查：
1. 视频格式是否支持（MP4/AVI/MOV）
2. 文件大小是否超过500MB
3. 网络连接是否稳定
4. 浏览器是否最新版本

如果问题仍然存在，尝试：
- 刷新页面重试
- 清除浏览器缓存
- 使用其他浏览器
- 压缩视频后再上传

#### Q3: AI分析不准确怎么办？

**A**: AI分析准确性受多种因素影响：

**视频拍摄**：
- 确保光线充足
- 避免背景复杂
- 保持摄像头稳定
- 完整拍摄投篮动作

**环境因素**：
- 篮球场地规范
- 避免遮挡
- 多人同时出现可能影响识别

如果多次分析都不准确，可以：
- 尝试重新上传更清晰的视频
- 联系技术支持

#### Q4: 实时训练模式延迟很高？

**A**: 延迟可能由以下原因导致：

**网络问题**：
- 检查网络速度（建议>=10Mbps）
- 关闭其他占用网络的程序
- 使用有线网络而非WiFi

**设备性能**：
- 关闭其他占用资源的程序
- 建议使用较新的电脑/手机

**服务器负载**：
- 高峰期可能延迟增加
- 尝试换个时间段使用

#### Q5: 忘记密码怎么办？

**A**: 
1. 点击登录页面的「忘记密码」
2. 输入注册邮箱
3. 检查邮箱收到的重置链接
4. 设置新密码
5. 使用新密码登录

如果没有收到邮件：
- 检查垃圾邮件文件夹
- 确认邮箱地址正确
- 联系管理员重置

#### Q6: 如何删除训练记录？

**A**: 
1. 进入「训练记录」
2. 找到要删除的记录
3. 点击「⋮」菜单
4. 选择「删除」
5. 确认删除

⚠️ 注意：删除后无法恢复，请谨慎操作

#### Q7: 可以导出数据吗？

**A**: 可以。进入「数据分析」页面：
1. 选择要导出的时间段
2. 点击「导出」按钮
3. 选择格式（Excel/PDF/CSV）
4. 下载到本地

#### Q8: 如何提高命中率？

**A**: 系统建议：

**观看AI分析**：
- 重点关注姿态评分低的部分
- 参考AI给出的改进建议

**学习课程**：
- 完成投篮技术课程

**持续练习**：

**寻求指导**：

### 技术问题

#### Q9: Docker启动失败？

**A**: 常见原因和解决方法：

**端口被占用**：
```bash
# 修改docker-compose.yml中的端口
ports:
  - "8001:8000"  # 改为其他端口
```

**Docker未运行**：
```bash
# 启动Docker Desktop（Windows/Mac）
# 或启动Docker服务（Linux）
sudo systemctl start docker
```

**权限问题**：
```bash
# Linux用户可能需要sudo
sudo docker-compose up -d
```

#### Q10: 数据库连接失败？

**A**: 检查：
1. MySQL服务是否运行
   ```bash
   docker-compose ps mysql
   ```

2. 查看日志
   ```bash
   docker-compose logs mysql
   ```

3. 检查配置文件`.env`中的数据库连接信息

#### Q11: 前端无法访问后端API？

**A**: 
1. 检查后端是否运行
   ```bash
   docker-compose ps backend
   ```

2. 检查`frontend/.env`中的API地址
   ```env
   VITE_API_BASE_URL=http://localhost:8000/api
   ```

3. 检查防火墙设置

#### Q12: GPU加速如何启用？

**A**: 如果你有NVIDIA GPU：

1. 安装NVIDIA Docker支持
2. 修改`docker-compose.yml`：
   ```yaml
   services:
     backend:
       deploy:
         resources:
           reservations:
             devices:
               - driver: nvidia
                 count: 1
                 capabilities: [gpu]
   ```

3. 重启服务
   ```bash
   docker-compose down
   docker-compose up -d
   ```

## 💡 使用技巧

### 提高训练效果

1. **规律训练**：每天固定时间训练，养成习惯
2. **设定目标**：为自己设定具体的提升目标
3. **认真分析**：每次训练后仔细查看AI分析
4. **及时调整**：根据反馈及时调整动作
5. **多样化练习**：不要只练投篮，全面发展

### 充分利用系统

1. **完成课程**：系统提供的课程都很有价值
2. **关注排行榜**：激励自己保持活跃
3. **参与社交**：向优秀的同学学习
4. **向教练请教**：遇到问题及时咨询
5. **记录心得**：在训练日志中记录感悟

### 视频拍摄技巧

1. **固定机位**：使用三脚架固定手机/摄像机
2. **横向拍摄**：横屏拍摄效果更好
3. **完整动作**：从准备到投篮完成都要拍到
4. **多角度**：可以从不同角度拍摄同一动作
5. **连续拍摄**：一次拍多个投篮，方便对比
